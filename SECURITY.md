# Security Policy

## Supported versions

Only the latest release, or the latest commit on the default branch, gets security fixes.

## Reporting a vulnerability

Please do not report security problems in public issues.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/abhichandra21/Promptheus/security/advisories/new).
Include what the problem is, how to reproduce it, and what impact you think it has.

This is a personal project maintained in spare time, so there is no guaranteed response time.
I will try to reply within a week and keep you updated until it is fixed.
